      自动部署
      
    
      为本地 CLI（arcunara deploy / watch）创建项目级部署密钥。密钥只能向本项目上传新版本和查询部署状态，不能管理分享、修改项目设置或回滚版本。完整密钥仅在创建时展示一次，服务端只保存哈希。
