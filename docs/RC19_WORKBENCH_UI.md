# RC19 — Arcunara Studio 工作台 UI 优化

## 目标与边界

本次仅更新 /console 的视觉设计与客户端交互，不改变 API、原型存储、分享和部署权限，不操作 VPS。

## 统一视觉设计

- 深色导航：#151e35；浅色内容区：#f5f7fc；卡片：#ffffff；主操作：#4f5de8。
- 页面层次：标题 → 生命周期统计 → 搜索及新建 → 项目列表 → 详情管理。
- 字体、边框、按钮、圆角、阴影、状态标签统一；深色侧栏在窄屏下变成水平导航。
- 1440px：两栏工作台；≤1180px：详情自然换行；≤820px：导航压缩、指标两列；≤640px：保留项目名称、版本与预览状态。
- 支持明显焦点、aria-pressed、aria-busy、role=search 和 prefers-reduced-motion。

## 交互与数据

1. 全部 / 进行中 / 已归档 / 回收站四项数字严格来自已鉴权的项目列表，不猜测指标；未连接展示横线。
2. 点击统计卡片切换状态筛选并清除当前搜索条件；不再展示与筛选不一致的详情。
3. 搜索名称或 ID，支持清空按钮、/ 与 Ctrl/Cmd+K 聚焦、Esc 清除（有 Dialog 时不抢键盘）。
4. 初次加载时显示骨架屏；请求过程标记 aria-busy 并禁用刷新按钮；失败时显示原因提示。
5. 项目详情、历史版本、分享链接、部署密钥并行读取；快速切换时只接受最后一次请求结果，避免旧项目覆盖新选择。
6. 匹配不到项目、回收站为空、没有归档项目、完全无项目均提供独立操作引导。
7. 用户文本仍以 textContent 显示；管理员 Token 仅存于内存，不存入 URL、浏览器存储或页面源码。
